# GRC103-Module3-Risk-Treatment-Lab

## Assignment Overview
This project presents a risk assessment and treatment plan for Northbridge Community Health, a fictional healthcare provider facing cybersecurity risks related to ransomware attacks.

The assessment includes:
- Risk identification and prioritisation
- Risk treatment selection within a $100,000 budget
- Insurance exposure calculations
- Response to a change scenario
- 30-day treatment plan
- Residual risk assessment
- Board-level decision memo
